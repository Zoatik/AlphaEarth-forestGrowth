# Semester project : Can  Deepmind's  AlphaEarth  Embeddings  be  used  to  infer  Forest Growth?

## Description
This four-week semester project is conducted as part of the third year of a Bachelor's degree at HES-SO Valais-Wallis, Switzerland, in preparation for the Bachelor's thesis.

The main objective is to investigate the potential of Google DeepMind's AlphaEarth Foundations embeddings for inferring forest growth, using data from the ICP Forests programme as reference data.

Given the exploratory nature and limited timeframe of this project, intermediate findings, data processing pipelines, and methodological insights are considered valuable outcomes in their own right and may serve as building blocks for future research.

## Objectives : 
- [ ] Centralize ICP and AEF (data + processing)
- [ ] Assess informations relevance and create a workable data pool
- [ ] Visual and statistical analysis
- [ ] Determine whether Deepmind's AlphaEarth Embeddings could be used to infer forest growth
